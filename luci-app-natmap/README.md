# luci-app-natmap

NATMap 的 LuCI 管理界面（支持 LuCI2 / OpenWrt 23.0+）。

打洞成功后支持联动 qBittorrent / Transmission / Emby / Cloudflare，
并支持 Telegram Bot / PushPlus / Server酱 / Gotify 消息通知。

- 支持版本：OpenWrt 23 及以上（旧版 OpenWrt 使用 luci1，不兼容本分支）
- 项目说明、编译方法、配置说明与常见问题：见[仓库根目录 README](../README.md)
- 多语言翻译：`po/` 目录，更新翻译后可用 gettext 命令从 `natmap.js` 重新提取文本
